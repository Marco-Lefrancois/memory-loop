# 🧠 Paradigme LLM-Wiki v2 et Format OKF (Open Knowledge Format)

> [!ABSTRACT]
> Cadre d'interopérabilité mnémonique structurant la mémoire de l'IA en 4 tiers (Working, Episodic, Semantic, Procedural) avec rétention sélective et supersession explicite.

## 1. Principes Fondamentaux
- **4 Tiers de Mémoire** : Working (graph_execution_log.json), Episodic (/grill-me), Semantic (standards/adr-system/, docs/), Procedural (
ho_rules.yaml, .agents/skills/).
- **Supersession Explicite** : Remplacement traçable des règles obsolètes sans amnésie.
- **Ebbinghaus Decay** : Décroissance de priorité des observations éphémères non consolidées.
