# 🛡️ Checklist de Complétude & Validation BA — <PROJET>

> **Validateur** : <Lead BA / QA>  
> **Phase** : Phase 3 — Validate  
> **Objectif** : Zéro angle mort avant la présentation client ou la transmission dev.

---

## 1. Traçabilité des Besoins (RTM)
* [ ] Chaque exigence `REQ-XXX` est reliée à un entretien, document ou étude sourcé.
* [ ] Aucune exigence ne repose sur une hypothèse non confirmée.

## 2. Étanchéité du Périmètre (Scope Boundary)
* [ ] La section *In-Scope* liste explicitement les livrables garantis.
* [ ] La section *Out-of-Scope* énumère clairement les éléments exclus ou différés.
* [ ] Les dépendances critiques sous responsabilité du client sont assorties d'une date butoir.

## 3. Clarté Métier & Absence de Jargon
* [ ] Zéro syntaxe de code ou Gherkin dans le corps du devis fonctionnel.
* [ ] Les règles de gestion (`RG-XX`) couvrent les cas nominaux et les exceptions d'affaires.

## 4. Approbation Client
* [ ] Signature / Accord formel recueilli sur le Devis Fonctionnel.
