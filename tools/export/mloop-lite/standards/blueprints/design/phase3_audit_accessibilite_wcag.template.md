# ♿ Checklist d'Accessibilité & Ergonomie — <PROJET>

* [ ] **Contraste des couleurs** : Ratio minimal de 4.5:1 pour le texte standard.
* [ ] **Taille des zones de clic** : Minimum 44x44 pixels pour les interactions tactiles mobiles.
* [ ] **Textes alternatifs** : Toutes les images porteuses de sens ont un attribut `alt` explicatif.
* [ ] **Structure des titres** : Hiérarchie logique H1 -> H2 -> H3 sans saut de niveau.
* [ ] **Formulaires explicites** : Tous les champs ont un label visible et une indication claire des erreurs.
