# Product Context — mLoop

## 1. Why this project exists
Les agents de code autonomes souffrent fréquemment d'amnésie de contexte, de sauts de phase intempestifs et de destructions silencieuses de code. mLoop élimine ces dérives.

## 2. User Workflows
1. Cadrage & Ingestion : Ingestion des documents et code source sans altération.
2. Analyse & Grill-Me : Entrevue contradictoire 1:1 pour éliminer les zones d'ombre.
3. Build Délégué : Délégation d'implémentation à des workers isolés via Herdr.
4. Certification QA : Fact-Check NLI, Vibe-Check pré-vol et suites pytest.
5. Livraison Fail-Closed : Publication Git et Jira sous validation stricte des invariants.
